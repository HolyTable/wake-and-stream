# 1 – Prepare the PC

Goal: the PC can be woken by a magic packet, can be reached by Remote Desktop, and logs in on its own.

> Menus and names differ between mainboards and Windows versions – look for similar wording.

## 1.1 BIOS / UEFI

| Setting | Value | Why |
|---|---|---|
| **ErP / EuP** (energy saving in soft-off) | **Disabled** | With ErP on, the network card has no power when the PC is off – no Wake-on-LAN |
| **Wake on LAN / Power on by PCIe** | **Enabled** (if present) | some boards need it explicitly |
| *(optional, see [security](security.md))* **AC Back / Restore on AC power loss** | Always On | lets a smart plug restart a frozen PC |

## 1.2 Windows: network card

Device Manager → *Network adapters* → your wired card → **Properties**

- **Power Management:** ✅ *Allow this device to wake the computer* · ✅ *Only allow a magic packet to wake the computer*
- **Advanced:** *Wake on Magic Packet* = Enabled · *Wake on pattern match* = **Disabled** (otherwise random network traffic wakes the PC)

## 1.3 Windows: fast startup off

`powercfg.cpl` → *Choose what the power buttons do* → *Change settings that are currently unavailable* →
uncheck **Turn on fast startup**. With fast startup the PC doesn't really shut down and often ignores
magic packets.

## 1.4 Remote Desktop

Settings → System → **Remote Desktop** → On. (Windows **Pro** or higher.)

## 1.5 Fixed IP address

Give the PC a fixed IP in your router (e.g. FRITZ!Box: Home Network → Network → the PC → *Always assign
this IPv4 address*). Note the **IP** and the **MAC address** – you need both for UpSnap.

## 1.6 Password + automatic logon

Remote Desktop needs a **password** on the Windows account (a PIN is not enough). If you like the PC to
start without asking for it at the desk:

1. Set a password (Settings → Accounts → Sign-in options → Password).
2. `Win+R` → `netplwiz` → uncheck *Users must enter a user name and password* → enter the password once.
   (If the checkbox is missing: Settings → Accounts → Sign-in options → turn off *For improved security,
   only allow Windows Hello sign-in*.)
3. Settings → Accounts → Sign-in options → *If you've been away, when should Windows require you to sign
   in again?* → **Never**.

> Trade-off: anyone who switches the PC on at home is logged in. See [security](security.md).

## Test

Shut the PC down, then wake it from the router (FRITZ!Box: device details → *LAN* tab → *Start computer*).
If it boots, Wake-on-LAN works.
