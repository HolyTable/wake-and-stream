# 12 – PlayStation 5 (optional)

Wake your PS5 from the Mac and play it through **[chiaki-ng](https://github.com/chiaki-ng/chiaki-ng)**
(a free Remote Play client), at home or away through the same VPN/Tailscale as the PC.
Nothing of the PC part (UpSnap, Apollo, Moonlight) is used here – the PS5 has its own protocol.

| What | How |
|---|---|
| Is it on? | the Mac sends a small UDP "search" to port **9302**; the PS5 answers *on* or *rest mode* |
| Wake up | a UDP "WAKEUP" packet with the Remote Play key chiaki-ng received when pairing |
| Play | `chiaki-ng stream <console name> <PS5 IP>` |
| Turn off | not remotely – in the stream: **PS button → Power → Enter rest mode** |

All of it is plain unicast UDP/TCP, so it works through a VPN or a Tailscale subnet route, unlike the
official PS Remote Play app, which finds the console by broadcast and then fails away from home.

## Limits

- The PS5 can only be woken from **rest mode**, not when it is switched off completely.
- Latency: at home it feels like playing on the TV; across a continent (e.g. Asia → Europe, ~250 ms)
  only slow games are fun – turn-based, strategy, story games. Shooters and racing games are not.
- While you stream, nobody can use the PS5 on the TV.

## Setup

1. **PS5** – *Settings → System → Power Saving → Features Available in Rest Mode*:
   turn on **Stay Connected to the Internet** and **Enable Turning On PS5 from Network**.
2. **PS5** – *Settings → System → Remote Play*: turn on **Enable Remote Play**.
3. **Router** – give the PS5 a fixed IP (like the PC).
4. **Mac** – install chiaki-ng from its [releases page](https://github.com/chiaki-ng/chiaki-ng/releases)
   (the `.dmg` for macOS) and move it to *Applications*.
5. **Mac, at home** – open chiaki-ng, let it find the PS5 and **pair** it once
   (it asks for your PSN account and the 8-digit code from *Settings → System → Remote Play → Link Device*).
   Test a stream once in chiaki-ng itself.
6. **Mac** – add the PS5's IP to `~/.config/wake-and-stream/config`:
   ```
   PS5_IP=192.168.1.60
   ```
7. Check everything:
   ```
   pc ps5 doctor
   ```
   It reads the console name and the Remote Play key from chiaki-ng's settings
   (`~/Library/Preferences/com.chiaki.Chiaki.plist`). If it cannot find them, fill in `PS5_NAME`
   (as shown in chiaki-ng) and `PS5_REGISTKEY` in the config.

A DualSense controller works on the Mac via USB-C or Bluetooth (hold **PS + Create** until the light
bar flashes, then pair it in *System Settings → Bluetooth*).

## Commands

```
pc ps5            on, rest mode, or not reachable?
pc ps5 on         wake it from rest mode and wait until it is ready
pc ps5 play       wake if needed + open the stream in chiaki-ng
pc ps5 stop       close chiaki-ng (the PS5 stays on)
pc ps5 doctor     check the PS5 part (also part of "pc doctor")
```
German: `pc ps5 an | spielen | stopp | doktor`. `PS5_FULLSCREEN=yes` in the config opens the stream
in full screen.

## Widget

The widget app also offers a second widget, **Wake and Stream – PS5** (small and medium): state of the
PS5, *Play* / *Wake up* from rest mode (with a "really …?" step), *End play* while chiaki-ng is open.
Add it like the PC widget ([docs/10-widget.md](10-widget.md)). Without `PS5_IP` it says *Not set up*.

## Troubleshooting

| Symptom | Cause / fix |
|---|---|
| *PS5 does not answer* | switched off completely, the two rest mode options from step 1 are off, or `PS5_IP` is wrong |
| Wakes at home, not away | VPN/Tailscale off, or the Tailscale subnet route does not include the PS5's network |
| *No Remote Play key found* | pair the PS5 in chiaki-ng first (step 5), or set `PS5_REGISTKEY` |
| Stream starts, black window | chiaki-ng: *Settings → Video → Renderer* → try OpenGL (`--opengl` once) |
