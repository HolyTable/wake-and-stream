# 8 – Streaming to a TV (Samsung / Tizen)

The TV runs **Moonlight** (the client), the PC runs Apollo (the server). Tizen TVs (about 2020 and newer)
can run community builds of Moonlight that are installed in developer mode.

## 8.1 Install

1. Put the TV into **developer mode** with your PC's IP as host (Apps → type `12345` on the remote → On).
2. Install with [Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung) (GUI or CLI):
   ```powershell
   apps2samsung-cli scan
   apps2samsung-cli install "C:\path\to\Moonlight.wgt" --tv 192.168.1.60
   ```
   - **"Subnet mismatch"** → a VPN on the PC (e.g. NordVPN) is active; disconnect it for the install.
   - The TV gets a **different IP on Wi-Fi and on LAN** – run `scan` again after changing the cable.
3. Pair like on the Mac (PIN → Apollo), then in Apollo allow **Launch apps** and **Controller input** for
   the TV (otherwise *403*).

## 8.2 Which Moonlight build?

The catalog (`apps2samsung-cli catalog moonlight`) lists several builds. Our experience on a 2022 Tizen
6.5 QLED:

| Build | Result |
|---|---|
| brightcraft v1.20 (also *ForceGM*) | modern, many settings – but **~0.5 s controller lag**, even in the app's own menu |
| **OneLiberty v1.2.1** | fewer settings, controller lag **gone** ✅ |

Different builds are signed by different authors: switching needs
`apps2samsung-cli uninstall MoonLightS.MoonlightWasm --tv <ip>` first (pairing and settings are lost).

## 8.3 Settings

4K · 60 FPS · HEVC · *Play audio on host* off · *Game optimizations* off · frame pacing + audio sync on ·
**HDR off** (the virtual display reports a very high peak brightness, so HDR looks washed out/too bright;
alternatively lower *SDR content brightness* in Windows' HDR settings while streaming).

A 4K stream upscaled by the TV looks better than trying 8K.

## 8.4 Game mode and latency

Samsung only allows *Game Mode* for HDMI sources, not for apps – so the TV's picture processing stays
active. Turn off *Picture Clarity / Auto Motion Plus*, *Contrast Enhancer* and *Noise Reduction* while
streaming. For the lowest latency use a streaming stick on HDMI (Apple TV, Fire TV 4K Max, Shield) –
there the TV's game mode works.

## 8.5 Ending the session

Leaving the app with *Home* only **pauses** – the PC's monitors stay off. Either select the running app
and choose **Quit**, use the controller combo (*Start + Select + L1 + R1*, then quit the app), or end it
from any browser: Apollo web UI → *Applications*.

## 8.6 Controller

A PS5/Xbox controller pairs with the TV via Bluetooth (TV settings → Connection → External Device
Manager → Input Device Manager). On the PC the **ViGEmBus** driver emulates it (installed with
Sunshine/Apollo). Games may show Xbox buttons: A = ✕, B = ○, X = □, Y = △.
